    Siri Shortcut

    Talk to Tana with your phone locked: say “Hey Siri, Tana”. A key can only send questions to Tana (no history, no board controls, no Claude Code). Delete it here if your phone is lost.

    Copy this key now — it won't be shown again:

    1. Open the Shortcuts app → + → name it Tana.
    2. Add Dictate Text (Stop Listening: After Pause).
    3. Add Get Contents of URL: https://your-tana-address/api/shortcut/say
      Method POST; Header Authorization = Bearer + space + your key; Request Body JSON with field text = Dictated Text.
    4. Add Get Dictionary Value for key speak, then Speak Text.
    5. Say “Hey Siri, Tana”. With the car screen open, the answer plays in the car; otherwise Siri reads it.
